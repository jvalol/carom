# carom

Thirteen marbles in a ring and one to shoot with [COPY - Jake]

Knock them out of the ring and they are yours. Your shooter stays where it
stops, so the shot that clears a marble nearest the edge is the shot that sends
you out after it, and the one that takes a marble further in leaves you in the
middle with everything still to shoot at. [COPY - Jake]

Built on [blitzkit](https://github.com/jvalol/blitzkit), the ninth game on that
engine, and the first where one body meets another. [COPY - Jake]

A carom is a shot where one ball strikes another, which is the half of the
engine's spec 0030 that no game had used. Every shot here is one, so the rule
can be checked without a window and what the tests assert is what the screen
draws. [COPY - Jake]

```
cargo run
```
